# 🎓 실시간 강의 소통 및 Q&A 투표 서비스

강의자와 학생들이 웹 및 모바일 환경에서 실시간으로 대화하고 소통할 수 있는 인터랙티브 강의 플랫폼입니다.

---

## ✨ 핵심 기능 요약

### 1. 🎙️ 강의자(Instructor) 기능
- **접속 URL**: `/instructor` (예: `http://localhost:5173/instructor` 또는 `http://<내IP>:3001/instructor`)
- **입장 비밀번호**: `1937`
- **학생 접속용 QR 코드 제공**:
  - 버튼 클릭 한 번으로 스마트폰 카메라로 스캔 가능한 고해상도 QR 코드 팝업 제공
  - 접속 URL 복사 및 로컬 네트워크 IP 자동 감지
- **질문 관리**:
  - **객관식(투표형)**: 보기 항목 자유롭게 추가/삭제 (최소 2개 이상)
  - **주관식(서술형)**: 자유 텍스트 피드백 수집
  - 질문 등록 즉시 출제 또는 나중에 시작 선택 가능
  - 질문 시작(전송) / 진행 종료(비활성화) / 삭제 제어
- **실시간 응답 현황 대시보드**:
  - 접속 학생 수 및 응답률(%) 실시간 집계
  - 객관식: 선택지별 득표수, 퍼센트(%), 프로그레스 바 그래프, 선택한 학생 뱃지(동물 아이콘 + 캐릭터명) 실시간 표시
  - 주관식: 학생들이 제출한 답변 카드 그리드 (실시간 카드 등록 및 내용 갱신)

### 2. 📱 학생(Student) 기능
- **접속 URL**: `/` (예: `http://localhost:5173/` 또는 강의자가 제공한 QR 코드로 모바일 접속)
- **입장 비밀번호**: `1234`
- **익명성 및 고유 캐릭터 부여**:
  - 접속 시 중복되지 않는 고유 캐릭터명과 귀여운 동물 아이콘 자동 배정 (예: 🦁 용감한 사자, 🦊 행복한 여우, 🐨 다정한 코알라 등)
  - 모바일 브라우저 새로고침 시에도 동일한 캐릭터 프로필 유지
- **실시간 질문 동기화**:
  - **진행 중인 질문이 없을 때**: *"질문이 없습니다"* 대기 애니메이션 화면 표시
  - **강의자가 질문을 보냈을 때**: 즉시 진동/시각 효과와 함께 응답 화면으로 전환
  - **답변 수정 가능**: 강의자가 다음 질문으로 넘어가기 전까지 원하는 만큼 선택지 변경 또는 주관식 답변 수정 가능!

## 🚀 빠른 시작 방법

### 1. 의존성 설치 (최초 1회)
```bash
npm install
```

### 2. 실행 모드

#### A. 개발 모드 (Vite HMR + Nodemon)
```bash
npm run dev
```
- 프론트엔드 (Vite): `http://localhost:5173`
- 백엔드 (Express + Socket.IO): `http://localhost:3001`

#### B. 프로덕션 실행 (단일 서버)
```bash
npm run build
npm start
```
- 서비스 접속: `http://localhost:3001`

### 3. 기능 자동 검증 테스트 실행
```bash
# 서버가 3001번 포트에서 실행 중일 때
npm test
```
- 소켓 연결, 인증(1937/1234), 닉네임 고유 배정, 실시간 질문 출제, 학생 답변 제출 및 수정, 강의자 집계 수신, 질문 종료를 모두 자동으로 테스트합니다.

## 📱 스마트폰(모바일) 테스트 가이드
1. 컴퓨터와 스마트폰을 **같은 Wi-Fi(공유기)**에 연결합니다.
2. 컴퓨터에서 강의자 페이지(`http://localhost:5173/instructor`)에 접속하고 비밀번호 `1937`을 입력합니다.
3. 상단의 **[학생 참여 QR]** 버튼을 클릭합니다.
4. 스마트폰 카메라로 QR 코드를 스캔하여 접속합니다. (비밀번호: `1234`)
5. 강의자가 질문을 등록하고 시작하면 스마트폰 화면이 실시간으로 전환되는 것을 확인할 수 있습니다!
